# Josué Santos Tech

Site oficial desenvolvido em HTML puro, CSS moderno e JavaScript vanilla. Sem dependências externas de compilação, pronto para abrir localmente ou publicar em qualquer servidor web.

## Estrutura de Pastas

* `index.html`: código fonte completo da página, estruturado para alta conversão e velocidade de carregamento.
* `assets/`:
  * `logo.png`: logotipo da Josué Santos Tech para o cabeçalho.
  * `favicon.png`: ícone do prisma para a aba do navegador.
  * `josue-santos.jpg`: foto oficial de Josué Santos em alta definição.
  * `hero-bg.jpg`: fundo cinematográfico do hub tecnológico.
* `server.js`: servidor leve em Node.js para testar localmente.

## Como Visualizar no Computador

Você tem duas opções simples:

1. Clique duas vezes no arquivo `index.html` para abrir diretamente no seu navegador.
2. Ou inicie o servidor local abrindo o terminal nesta pasta e rodando:
   `node server.js`
   Depois acesse: `http://localhost:3000/`

## Como Publicar na Internet

Quando decidir colocar no ar, basta enviar todo o conteúdo desta pasta para a sua hospedagem:

* **HostGator ou cPanel:** envie os arquivos para a pasta `public_html`.
* **Vercel ou Netlify:** arraste a pasta ou conecte seu repositório Git.
